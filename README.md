
# Textroverse – Text to Image Customization Tool

Textroverse is a web application that allows users to convert text into images and customize them using various visual filters and adjustments. The platform enables users to modify image properties such as brightness, contrast, and saturation, apply filters, and download the final image for use in social media, marketing, or personal projects.

# 🚀 Key Features

### Text-to-Image Generation
Users can generate images by entering text, which is converted into an image using an external API.

### Customizable Image Filters
Adjust image properties including:
- Brightness
- Contrast
- Saturation

Apply visual filters such as:
- Grayscale
- Sepia
- Inverse

### Real-Time Image Modifications
Image adjustments are applied instantly, allowing users to preview changes in real time.

### Download Customized Images
Once the image is finalized, users can download the customized version for use in various applications.

### Simple and User-Friendly Interface
A clean and intuitive interface designed for users without design experience, making it accessible for designers, marketers, and general users.

---

# ⚙️ How It Works

### Text-to-Image Generation
Textroverse uses the **Pollination API** to generate images from user input. When a user enters text into the input field, the application sends a request to the API, which processes the text and returns a generated image.

### Real-Time Image Adjustments
JavaScript is used to apply real-time changes to the image. Adjustments such as brightness, contrast, and saturation are applied by manipulating pixel values and updating the image dynamically.

### Image Customization and Download
After the user customizes the image with filters and adjustments, the application allows them to download the final image generated by the server.

## Image Processing
JavaScript – Pixel-based image adjustments

# 🏁 Getting Started

Follow these steps to run Textroverse locally.

---

## Prerequisites

Ensure the following are installed:

Node.js (v16 or higher)  
npm or yarn  
A modern web browser  

---

# ⚙️ Installation

### Clone the Repository

```
git clone https://github.com/desaishro/textroverse.git
cd textroverse
```

### Install Dependencies

```
npm install
```

---

# ▶️ Running the Application

Start the server:

```
npm start
```

Then open the application in your browser:

```
http://localhost:3000
```
